# HOI4 Modding Studio - Refactored Application

This is the refactored version of the HOI4 Modding Studio application.
The original single-file application has been split into multiple modules
for better organization and maintainability.

## Structure

- `src/main.py` - Main application entry point
- `src/settings.py` - Settings management
- `src/localisation.py` - Localisation utilities
- `src/tags.py` - Country tags management
- `src/countries.py` - Country creation functionality
- `src/states.py` - State management
- `src/events.py` - Event system
- `src/focus.py` - Focus tree system
- `src/utils.py` - Utility functions
- `src/mod_finder.py` - Mod finding functionality

## Usage

Run the application using `python hoi4_modding_studio_single_patched.py`
